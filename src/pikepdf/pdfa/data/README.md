# PDF/A validator data

Data files for `pikepdf.pdfa`.

- `verapdf_rules.json` — rule catalogue for PDF/A-1b, 2b and 3b, generated by
  `misc/import_verapdf_profiles.py` from the veraPDF validation profiles.
- `dispositions.json` — how the pikepdf validator handles each catalogue rule
  (hand-maintained; `tests/test_pdfa_catalogue.py` checks it is complete).
- `schemas/` — JSON Schemas for the shallow encoding of each object role.
- `xmp_properties.json` — XMP namespaces and properties accepted per flavour.
- `sRGB.icc` — the sRGB ICC profile used for PDF/A output intents.
